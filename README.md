# Freshwater Shrimp Aquascaping 🦐

### Interactive JavaScript Website | BYU-Idaho

## About the Project

This project is a beginner-friendly educational website about freshwater shrimp aquascaping, created as part of a JavaScript assignment at Brigham Young University-Idaho.

The website introduces visitors to the basics of setting up and maintaining a freshwater shrimp aquarium, including recommended supplies, aquatic plants, aquarium cycling, and shrimp care.

The primary goal of this assignment was to practice JavaScript fundamentals while creating an interactive and visually appealing website.

## Technologies Used

- **HTML** — Structured the website's content and sections.
- **CSS** — Created a responsive layout with an aquarium-inspired color palette.
- **JavaScript** — Added an interactive shrimp-care tip generator.

## JavaScript Features

The website includes an interactive **Random Shrimp Care Tip Generator**.

When visitors click the "Show Me a Tip" button, JavaScript selects a shrimp-care tip from an array and dynamically displays it on the webpage without requiring a page refresh.

This feature demonstrates several foundational JavaScript concepts:

- Arrays and variables
- Functions
- Random number generation using `Math.random()`
- Array indexing
- DOM manipulation using `document.getElementById()`
- Event handling and dynamic content updates
